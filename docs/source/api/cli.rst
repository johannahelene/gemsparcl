gemsparcl.cli
=============

Command-line interface built with `Click <https://click.palletsprojects.com>`_ and `rich-click <https://github.com/ewels/rich-click>`_.

This module defines the two top-level commands (``cluster`` and ``query``) and the ``save_config`` helper that persists run parameters for future queries.
